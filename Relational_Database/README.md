## Introduction
In this task, you will replicate this common process. You will take external data from a comma-separated values (CSV) file and design a logical data model that describes the data. You will then load the data into a database solution and run queries across it.

Choose either "Scenario 1" or "Scenario 2" from the Supporting Documents, along with the scenario's associated CSV file. You will design a relational database solution, implement the solution, and present the solution (using Panopto) to an audience that consists of your peers within a project team.



## Part 1: Design Document 

A.  Select either "Scenario 1" or "Scenario 2" from the Supporting Documents and complete the following:

    1.  Describe a business problem within the chosen scenario that can be solved with a database solution.

        a.  Propose a data structure to solve the business problem described in part A1.

        b.  Justify why a database solution will solve the business problem described in part A1.



B.  Create a logical data model for storing data in the database solution.

    1.  Explain how the business data will be used within the database solution.

    2.  Describe the database objects and storage, identifying the file attributes within the database solution.



C.  Discuss how the proposed database design addresses scalability concerns, including strategies that align with the chosen scenario to ensure the database can handle growth and increased demand.



D.  Outline the privacy and security measures that should be implemented in the proposed database design.


Note: You are not required to implement these privacy and security measures in this task.
